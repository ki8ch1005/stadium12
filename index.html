📚 現役・歴代 応援歌カタログ

既存のクイズ収録曲に加え、外部資料の選手名・球団名・掲載年など、歌詞以外の情報を収録しています。カタログ収録＝歌詞を利用できる・実際にクイズで出る、という意味ではありません。 歌詞は権利者から使用許諾を得たもの、または自分で利用権限を確認したものだけ登録してください。

参照先：過去の応援歌一覧 ／ 楽曲資料。出典に載る選手の現役・OB区分は移籍や引退などで変化します。掲載年は使用開始年を意味しません。個々の楽曲や年代の正確性は追加検証が必要です。

Excel / CSV / JSON を一括読み込み

曲数を増やしたいときは、表計算ソフトでデータを作成して読み込めます。読込後は自動的にクイズへ反映されます。

Excelテンプレートは別途ダウンロードして使用してください。

Excel・CSV列名：player,team,lyrics,era,difficulty,aliases,year,source
文字コード：UTF-8（BOM付きも可）。同一選手でも異なる歌詞は別曲として登録できます。
